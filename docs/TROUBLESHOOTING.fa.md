# عیب‌یابی

## Node.js پیدا نشد

Node.js 22.12.0 یا بالاتر نصب کن، سپس پنجره PowerShell را ببند و دوباره باز کن.

## Antigravity در حال اجراست

همه پنجره‌ها و پردازش‌های پس‌زمینه Antigravity را ببند و دوباره تلاش کن.

## Unsupported runtime

نسخه نصب‌شده در preflight پروژه اصلی شناخته نشده است. Patch را به‌زور اعمال نکن. نسخه Antigravity، متن کامل خطا و فایل لاگ را برای issue آماده کن.

## مدل AvalAI نمایش داده نمی‌شود

- Provider را Enabled کن.
- شناسه دقیق مدل را بررسی کن.
- Base URL را با `/v1` وارد کن، نه با `/v1/v1`.
- اگر فهرست مدل‌ها در دسترس نیست، Model ID را دستی وارد کن.
- API Key را بررسی کن.

## خطاهای API

- 401: کلید نادرست یا هدر نامعتبر
- 403: مجوز یا دسترسی حساب
- 404: endpoint یا model ID نادرست
- 429: محدودیت نرخ یا اعتبار
- 5xx: اختلال سرویس ارائه‌دهنده یا upstream

## برنامه پس از آپدیت باز نمی‌شود

فایل‌های قدیمی را دستی کپی نکن. ابتدا مستندات recovery پروژه اصلی را بخوان و از Restore پشتیبانی‌شده استفاده کن. اگر runtime توسط آپدیت تغییر کرده، ممکن است نصب تمیز Antigravity لازم باشد.
