# اتصال AvalAI به Antigravity

یک پروژه همراه برای ویندوز جهت نصب و راه‌اندازی **Antigravity Custom Model Enabler** و اتصال API سازگار با OpenAI سرویس AvalAI به نسخه مستقل دسکتاپ Antigravity.

> **مهم:** این مخزن فایل اختصاصی Antigravity یا نسخه کپی‌شده Patch اصلی را توزیع نمی‌کند. در زمان نصب، پروژه اصلی را از GitHub رسمی دریافت می‌کند، آن را می‌سازد و ابتدا بررسی سازگاری را اجرا می‌کند. اگر بررسی ناموفق باشد، نصب را متوقف می‌کند.

## وضعیت پشتیبانی

- سیستم‌عامل هدف: Windows 10/11
- برنامه هدف: نسخه مستقل دسکتاپ Antigravity مبتنی بر Electron
- نسخه گزارش‌شده توسط کاربر: `2.29.0`
- مسیر مشاهده‌شده برنامه: `%LOCALAPPDATA%\Programs\antigravity\resources`
- **سازگاری نسخه 2.29.0 هنوز تأیید نشده است.** نتیجه بررسی رسمی پروژه بالادستی ملاک نصب است؛ این ابزار Patch را به نسخه ناشناخته تحمیل نمی‌کند.

## امکانات

- نصب‌کننده راهنمای PowerShell
- دریافت و ساخت پروژه اصلی از مخزن رسمی
- بررسی سازگاری پیش از نصب
- گرفتن تأیید صریح قبل از تغییر برنامه
- اسکریپت بازگردانی
- راهنمای اتصال AvalAI
- مستندات فارسی و انگلیسی
- عدم ذخیره API Key در سورس

## پیش‌نیازها

- Windows PowerShell 5.1 یا PowerShell 7
- Node.js نسخه 22.12.0 یا بالاتر (نسخه 22.13 به بالا پیشنهاد می‌شود)
- دسترسی اینترنت به GitHub و AvalAI
- بسته بودن کامل Antigravity هنگام نصب

نصب‌کننده وجود Node.js را بررسی می‌کند. نرم‌افزار دیگری را بی‌اجازه نصب نمی‌کند و Execution Policy ویندوز را به‌صورت دائمی تغییر نمی‌دهد.

## شروع سریع

1. مخزن را دانلود و از حالت فشرده خارج کن.
2. Antigravity را کاملاً ببند.
3. فایل `installer\Install.bat` را اجرا کن. معمولاً برای نصب کاربری نیازی به Administrator نیست.
4. مراحل را دنبال کن.
5. اگر بررسی سازگاری موفق بود، نصب را تأیید کن.
6. Antigravity را باز کن و به مسیر **Settings → Models & Usage → Custom Models** برو.
7. Provider سازگار با OpenAI را با اطلاعات فایل `docs/AVALAI-CONFIGURATION.fa.md` اضافه کن.
8. شناسه دقیق مدل را از حساب AvalAI بردار؛ نام مدل را حدس نزن.

## اطلاعات اتصال AvalAI

- آدرس پایه: `https://api.avalai.ir/v1`
- مسیر Chat Completions: `https://api.avalai.ir/v1/chat/completions`
- روش احراز هویت: Bearer Token
- کلید API: فقط در Model Manager محلی وارد شود؛ هرگز در GitHub قرار نگیرد.

بسته به عنوان فیلد در Model Manager، آدرس پایه یا Endpoint کامل را وارد کن. مسیر `/chat/completions` را دوبار اضافه نکن.

## پس از به‌روزرسانی Antigravity

آپدیت Antigravity ممکن است فایل‌های Patch‌شده را جایگزین کند. پس از هر به‌روزرسانی:

1. Antigravity را ببند.
2. `installer\Check-Compatibility.ps1` را اجرا کن.
3. اگر بررسی موفق بود، `installer\Install-AvalAI.ps1` را اجرا و نصب مجدد را تأیید کن.
4. اگر بررسی ناموفق بود، Patch را به‌زور نصب نکن و منتظر نسخه سازگار پروژه اصلی بمان.

پروژه اصلی اطلاعات بازگردانی را نگه می‌دارد و رفتار بازیابی خودش را مستند کرده است. این مخزن **نصب مجدد خودکار و بدون دخالت کاربر بعد از تمام آپدیت‌های Antigravity را تضمین نمی‌کند**. برای این کار باید سرویس پس‌زمینه جداگانه با رضایت کاربر و تست سازگاری طراحی شود.

## بازگردانی

در PowerShell از ریشه پروژه اجرا کن:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\Restore-Antigravity.ps1
```

عملیات بازگردانی به پروژه اصلی واگذار می‌شود و تابع بررسی‌های ایمنی آن است. نباید فایل‌هایی را که پس از آپدیت Antigravity تغییر کرده‌اند با نسخه قدیمی جایگزین کند.

## ارتباط با پروژه اصلی

این مخزن فقط ابزار همراه نصب و مستندسازی است. Patch اصلی، Model Manager و مسیریابی Providerها متعلق به پروژه زیر است:

- https://github.com/vahapogut/antigravity-add-model
- مجوز پروژه اصلی: Apache-2.0؛ شرایط به‌روز را در مخزن اصلی ببین.

## سلب مسئولیت

این پروژه وابسته، تأییدشده یا حمایت‌شده از طرف Google، Antigravity یا AvalAI نیست. سازگاری ممکن است با به‌روزرسانی برنامه تغییر کند.
